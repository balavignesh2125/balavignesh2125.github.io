
# Cubli — Three-Axis Edge Balancing

## Overview

A three-axis reaction-wheel-based balancing platform.
The accompanying video demonstrates the physical Cubli
balancing on an edge.

## Demonstration

See the video on the [portfolio homepage](../../).

## Implementation

The available C++ source snapshot includes embedded control
software, IMU processing, motor control, and an LQR implementation.
